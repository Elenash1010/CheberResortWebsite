# Перенос текущего сайта в Figma

Дата: 2026-09-05.

Файл: https://www.figma.com/design/hK1P3bDYYl1qdDuO9D32S6

Перенесены все 30 HTML-страниц текущей локальной версии сайта в настольном размере. Оформление, тексты и изображения импортированы в редактируемые слои. Подтверждены шрифты PT Sans и Raleway, отсутствующих шрифтов нет.

В файле две страницы:
- `01 — Полные страницы сайта` (`0:1`): полноразмерные макеты.
- `02 — Интерактивный прототип` (`37:2`): копии с областью просмотра 1410 × 1000 и вертикальной прокруткой. Несмотря на название, переходы ещё НЕ настроены: Figma MCP исчерпал лимит Starter на этапе сопоставления ссылок. Мобильные макеты не создавались.

Исходные HTML, CSS и JS не изменены. Временный сервер и профили браузера удалены.
